> 视频循环推流 + 弹幕实时互动 + AI 智能回复 + 电商自动化，一台电脑同时运营多个 TikTok 直播间。

## 一、软件简介

TikLive 是一款 Windows 桌面端 TikTok 直播自动化工具，核心能力：

| 模块 | 功能 |
|---|---|
| 多通道推流 | 同时管理多个直播间通道，各自独立配置、独立开播 |
| 视频循环推流 | 本地视频文件 7×24 小时循环推流，内置 ffmpeg 无需另装 |
| 弹幕采集 | 服务器端采集弹幕（进入/关注/点赞/评论/送礼/下单），零签名不限流 |
| 语音互动 | TTS 语音播报：关键词回复、进场欢迎、定时播报、下单感谢 |
| 文字互动 | 公屏文字自动回复：关键词、欢迎、播报、下单感谢 |
| AI 智能回复 | 接入大模型，自动回复观众提问，支持店铺 FAQ 与商品备注 |
| 卖点播报台 | 按顺序/随机循环播报商品卖点话术，支持 AI 改写 |
| 电商工作台 | 商品自动弹窗、违规检测命中自动下播、订单监控 |
| 稳定性 | 断流自动重新取码重连、弹幕断线自愈、被顶号/违规自动处理 |

## 二、安装与登录

1. 运行安装包 `TikLive_x.x.x_x64-setup.exe`，按提示完成安装（内置 ffmpeg，无需额外环境）。
2. 启动软件，输入**账号和密码**登录（账号由管理员发放）。
   - 登录状态会记住，下次启动自动进入。
   - 账号在别处登录、到期或被顶号时，会要求重新登录。
3. 续期：点开「软件授权」对话框，输入卡密点「兑换」，有效期自动顺延。
4. 软件更新：设置对话框内点「检查更新」，发现新版本可一键下载安装。

## 三、快速开播（三步）

左侧选择或新建通道后，在「推流」页完成开播必需三项：

### 第 1 步：选择视频文件
- 支持 mp4 / mkv / flv，已是 TikTok 规格的文件直接转发，不二次转码。

### 第 2 步：填写 TikTok 用户名
- 填主播 username（**不带 @**），用于弹幕连接。
- 可先点顶部「工作台」登录 TikTok 卖家账号，然后点「从工作台提取」自动填入。

### 第 3 步：获取推流地址和推流码
- **推荐**：点「一键获取」自动取码。
- 也可手动粘贴自己的推流地址（rtmp://…）和推流码。
- DID（设备 ID）留空自动提取。

三项齐全后点「开始直播」，推流码会先经过服务器校验交换，通过后正式开播。直播数据（评论/进场/点赞/关注/TTS 次数）在顶部实时显示，可点「数据窗」置顶小窗。

## 四、功能详解

### 1. 推流页
- **背景循环音乐**：选择音乐文件夹，mp3/wav 循环垫底播放；话术语音在前景，背景音量建议 15-35%，修改后重启通道生效。
- **通道与网络**：通道命名；代理支持 socks5（弹幕+音视频都走此出口）、http（仅弹幕）、vmess://、vless:// 链接（需在设置里配置 xray 路径）。
- **高级（音频管道）**：采样率/声道一般保持默认，由 TTS 返回音频自动适配。

### 2. 语音页（TTS 语音播报）
- **TTS 引擎**：填入 API Key 即可启用。
- **关键词回复**：观众评论命中关键词 → 播报对应语音，支持多条规则。
- **进场欢迎**：欢迎新进观众，可配置欢迎语与最小间隔。
- **定时播报**：按随机间隔循环播报预设话术（如活动、优惠信息）。
- **下单感谢**：检测到下单行为后语音感谢，独立冷却时间。

### 3. 文字页（公屏文字回复）
与语音完全独立的四类回复：关键词回复、进场欢迎、定时播报、下单感谢。各类别有独立开关，发送走官方公屏接口。

### 4. AI 页（智能回复）
- **AI 引擎**：默认 glm-4-flash，填 API Key 开启；可配置每分钟回复上限、单人冷却、回复长度。
- **系统提示词**：留空使用内置西语带货提示词。
- **店铺 FAQ**：配置发货时效/支付方式/退换政策等，观众问到按此回答，未覆盖的引导私信。
- **商品备注**：给主推商品填尺码对照表等备注，AI 优先按备注回答。

### 5. 电商页
- **违规检测**：轮询违规记录，命中自动下播保护账号（独立开关，可调轮询间隔）。
- **商品自动弹窗**：按顺序（sequential）或随机（random）模式定时弹出购物车商品，弹窗间隔可调。
- **卖点播报台**：循环播报商品卖点，支持 normal/random 模式与 AI 改写，可用独立 TTS Key。

### 6. 日志页
实时查看通道运行日志：推流状态、弹幕连接、取码、自动回复命中、违规检测等全流程事件。

## 五、常见问题

**Q：一键获取推流码失败？**
先确认已点「工作台」登录 TikTok 卖家账号且登录态有效；检查网络/代理；Studio 路线超时会自动走签名兜底路线，仍失败请查看日志页具体报错。

**Q：提示"推流码校验失败"？**
开播前推流码需经服务器校验交换。请检查授权是否到期（打开「软件授权」查看有效期）、网络能否访问授权服务器。

**Q：直播中途断流了？**
软件会自动重新取码并重建推流（最多 3 次，间隔 10 秒），全程无需人工干预；弹幕断线也会自动重连。

**Q：TTS 没有声音？**
确认语音页总开关已打开且填入了有效的 MiMo API Key；检查音频管道高级设置是否被改动。

**Q：AI 不回复？**
确认 AI 引擎开关与 API Key 有效；检查每分钟上限/单人冷却是否设得过小；自己发的公屏消息不会触发回复。

**Q：一台电脑能开几个直播间？**
通道数量不限，同时开播数量取决于电脑性能与上行带宽（单路 1080p 约需 2-4 Mbps 上行）。

**Q：账号可以换电脑用吗？**
账号与首次登录的机器绑定，换机需联系管理员解绑。
